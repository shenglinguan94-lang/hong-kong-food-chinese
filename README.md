# 香港美食與點餐華語

一個以香港飲食情境為主題的單頁互動華語教材。內容涵蓋茶餐廳、飲茶和街頭小吃，並列普通話拼音、香港廣東話與粵拼。

## 功能

- 19 個漸進式學習畫面
- 三組情境故事與即時答題回饋
- 普通話／廣東話並列比較
- 可自由組合餐點、口味和用餐方式的模擬點餐器
- 自動保存上次學習位置
- 支援手機、鍵盤操作與減少動態效果偏好

## 本機預覽

這是純靜態網站，直接開啟 `index.html` 即可。若瀏覽器限制本機資源，可在專案目錄執行：

```bash
python -m http.server 8000
```

然後前往 `http://localhost:8000`。

## 發布

推送到 `main` 分支後，GitHub Actions 會自動發布至 GitHub Pages。
